Cart total calculation fails with multiple discount codes

description Description

When a user applies a fixed-amount discount code (e.g., "$10 OFF") and then subsequently applies a percentage-based discount code (e.g., "15% OFF"), the final cart total calculates the percentage off the *original* subtotal rather than the subtotal after the first discount. This results in an unexpectedly large total discount, sometimes driving the cart total below zero.

integration_instructions Reproduction Steps

  1. Log in to the staging environment (user: test_buyer).
  2. Add "Premium Widget" ($100) to the cart.
  3. Navigate to checkout.
  4. Apply promo code MINUS10 ($10 off). Observe total is $90.
  5. Apply promo code FIFTEEN (15% off).
  6. Expected: Total should be $90 - ($90 * 0.15) = $76.50
  7. Actual: Total is $90 - ($100 * 0.15) = $75.00
