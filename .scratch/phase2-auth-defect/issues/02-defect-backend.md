# 02 — 缺陷管理后端

**What to build:** 完整的缺陷管理后端 API，覆盖模型、CRUD、状态机、模块管理、附件上传。

- 缺陷 ORM 模型（标题、描述、操作步骤、严重程度 P0-P3、优先级 P0-P3、状态、指派给、创建者、版本/Branch、模块、附件）
- 禅道完整状态机（未确认→已确认→处理中→已解决→已关闭，含解决方案）
- 缺陷模块管理（项目级模块树，CRUD）
- 附件上传到服务器文件系统
- 最近缺陷查询 API（按项目 + 版本）
- 操作日志记录
