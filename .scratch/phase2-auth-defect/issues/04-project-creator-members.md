# 04 — 项目创建者 + 成员管理

**What to build:** 项目创建者自动记录、项目成员管理功能。

- 项目表增加 creator_id，创建项目时自动记录创建者
- project_members 表 + 成员 CRUD API
- 用户搜索 API（/api/users/search?q=，按昵称或用户名搜索）
- 前端成员管理弹窗（搜索用户、添加、移除，不能移除创建人）
- 非成员用户只能看到自己参与或创建的项目
- 成员管理入口在项目详情面板中
