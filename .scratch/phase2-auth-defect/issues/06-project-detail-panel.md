# 06 — 项目详情面板

**What to build:** 项目列表页重构为左右分栏布局，右侧显示当前活跃项目的详情面板。

- 项目列表页重构为左右分栏（左侧项目卡片列表约 40%，右侧详情面板约 60%）
- 切换活跃项目时右侧详情同步更新
- 右侧面板从上到下排列：
  1. 项目备注（Markdown 渲染 + 编辑切换）
  2. 项目信息（名称、创建人、成员清单 + 管理入口）
  3. 最近缺陷（最近 2 条，"xxx 提交了 xxx（xx 时间之前）"）
  4. 最近测试任务（最近 2 条，任务名称 + 执行状态 + 时间，点击跳转测试执行页面）
