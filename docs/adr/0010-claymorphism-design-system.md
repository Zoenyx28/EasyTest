# ADR-0010: 前端设计系统转向 Claymorphism（黏土拟态）

## Status

Accepted

## Context

ADR-0008 确立了「蓝色 SaaS 风 + A 精修」的统一设计系统：主色蓝、8/12/16 圆角、Space Grotesk + DM Sans 字体、软阴影。该方案在组件规范化层面（基础组件抽象、token 单一来源、橙色约束）是成功的，但视觉上仍属传统 SaaS 后台风格，缺少辨识度。

在后续迭代中，用户希望产品外观更具亲和力与记忆点。经过一轮设计评审，团队决定将视觉语言整体切换为 **Claymorphism（黏土拟态）**：圆润大圆角、粗描边、硬偏移投影，营造"立体黏土"的活泼质感，与测试工具的严肃底色形成反差萌。

## Decision

### 视觉方向

- **风格**：Claymorphism。核心是 `--outline` 硬描边（亮色深灰 / 暗色浅灰，随主题切换）+ `--shadow-hard-*` 硬偏移无模糊投影（3/4/6px，按下收缩为 pressed 态、元素"下沉"）
- **配色**：主色从蓝改为**桃粉** `#FDBCB4`（仅装饰 / 选中态 / 焦点光环）；主按钮改用 **CTA 绿** `#22C55E`；新增 **Secondary 浅蓝** `#ADD8E6`（次级按钮）与糖果色点缀（`--lavender` / `--mint`）
- **圆角**：从 8/12/16 提升为 **12/16/24**（sm/md/lg），匹配 Clay 的圆润气质
- **背景**：亮色从冷白 `#F8FAFC` 改为**暖白** `#FFF9F5`，暗色基调不变
- **主题**：保留明暗双主题；暗色下硬描边转浅色（`#E2E8F0`）、硬阴影透明度提升，保证边界清晰

### 字体

- **替换**为 Fredoka（标题）+ Nunito（正文），仍为 OFL 开源协议、自托管于 `frontend/public/fonts/`；JetBrains Mono（代码）不变
- 删除原 Space Grotesk / DM Sans 字体文件，保留其 OFL 许可证文本（Fredoka/Nunito 新增许可证文件随仓库提交）
- **中文仍走系统字体栈**，不引入中文字体文件

### 组件形态

- 基础组件（BaseButton / BaseInput / BaseDialog / BaseTag）全部迁移到 Clay 语言：粗硬描边 + 硬阴影 + 大圆角 + 按压下沉交互
- 导航栏 3px 底部硬描边，激活 Tab = 桃粉底 + 硬描边 + 硬阴影；弹窗面板 = 3px 硬描边 + `--shadow-hard-lg` 与 `--shadow-dialog` 叠加
- 软阴影体系（`--shadow-*`）保留，用于弹层浮起与卡片悬浮

### 与 ADR-0008 的关系

- **继承**：token 单一来源、基础组件规范化、紧凑表格行高、橙色仅用于高风险操作/警告/P0-P1 等约束全部沿用
- **取代**：ADR-0008 中「蓝色 SaaS 风 + A 精修」的配色 / 圆角 / 字体部分被本决策取代；`design.md` 已同步重写为 Claymorphism 规范

## Considered Options

- **继续蓝色 SaaS 风（A 精修）**：风格安全但缺乏辨识度，未选
- **Neumorphism（新拟态）**：柔和内阴影、同色系无描边，可访问性差（低对比度）、与既有组件改造冲突大，未选
- **Glassmorphism（玻璃拟态）**：作为辅助手段保留（导航栏/侧栏 blur），但大面积使用会牺牲信息密度，未整体采用
- **主按钮继续用蓝**：Clay 质感下蓝色与桃粉/暖白搭配不协调，改选 CTA 绿作为行动号召，对比更鲜明

## Consequences

- **Positive**：视觉辨识度高、亲和力强，与产品调性形成差异化
- **Positive**：硬描边 + 硬阴影的组件语言一致性强，新页面复用成本低
- **Positive**：明暗双主题下 token 自动适配，`--outline` 单一来源避免描边色失控
- **Negative**：粗描边在紧凑列表/表格中占用空间，需控制只在关键控件上使用
- **Negative**：既有组件需分批迁移到 Clay 语言，改动量较大（与 ADR-0008 的组件替换工作叠加进行）
- **Negative**：字体切换后字号/字重观感有变化，需在 0 号界面过一遍视觉回归
