# 分诊标签

各技能使用五个规范分诊角色。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| 技能中的标签（mattpocock/skills） | 本仓库跟踪器中的标签 | 含义                                   |
| --------------------------------- | -------------------- | -------------------------------------- |
| `needs-triage`                    | `needs-triage`       | 维护者需要评估该 issue                 |
| `needs-info`                      | `needs-info`         | 等待报告人提供更多信息                 |
| `ready-for-agent`                 | `ready-for-agent`    | 已完全定义，可供 AFK 代理处理          |
| `ready-for-human`                 | `ready-for-human`    | 需要人工实现                           |
| `wontfix`                         | `wontfix`            | 不会处理                               |

当某个技能提到某个角色（例如"应用 AFK-ready 分诊标签"）时，请使用本表中的对应标签字符串。

编辑右侧列，使其与你实际使用的词汇保持一致。
